## Time Tracker v1.2.4

Bug fixes:

- Edit mode no longer swaps the row — the card smoothly expands with details underneath
- Details panel shows rename field, totals, last-used and status inline
- Delete confirms inline (tap twice) instead of a blocking dialog
- Typing a rename is no longer interrupted by the live timer refresh

**Download:** `time-tracker-1.2.4.apk` below, or the stable link on the
[download page](https://dnbdj.github.io/time-tracker/).
