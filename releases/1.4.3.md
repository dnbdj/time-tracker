## Time Tracker v1.4.3

Bug fix — the side-border/overflow issue, fixed for real this time:

- Found the actual cause: the screen's `fitsSystemWindows` flag was silently
  discarding the page padding and replacing it with system-bar insets — which
  are **zero on the left/right sides** with gesture navigation. Content has
  been sitting flush against the screen edges on every version so far.
- On Android 15/16 the app also drew edge-to-edge (targetSdk 35+ enforces it),
  so bottom rows could slide under the navigation bar.
- Now the app applies real insets itself: status bar, navigation bar, keyboard
  and camera cutout are all padded away on every Android version.
- New: a visible border frames the whole screen, so tasks clearly sit inside
  the display on any device or screen size.

**Download:** `time-tracker-1.4.3.apk` below, or the stable link on the
[download page](https://dnbdj.github.io/time-tracker/).
