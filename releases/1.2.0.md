## Time Tracker v1.2.0

- Stop button turns red while its timer runs (green otherwise)
- Smaller, centered edit button; Start stays far right
- Curved card borders — green glow on running tasks
- Edit mode gains Export to: Google Calendar (direct event), Outlook (.ics file), CSV row
- Swipe left/right actions, configurable in Settings: Delete, Archive, Mark as completed
- Filter chips: Open / Done / Archived / All; status survives device restarts

**Download:** `time-tracker-1.2.0.apk` below, or the stable link on the
[download page](https://dnbdj.github.io/time-tracker/).
